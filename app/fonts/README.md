# Fonts

Self-hosted so the app never depends on Google Fonts at build or run time.
Both are Latin-subset variable fonts downloaded from Google Fonts.

| File                                 | Font                                                 | Licence                   |
| ------------------------------------ | ---------------------------------------------------- | ------------------------- |
| `newsreader-latin-variable.woff2`    | Newsreader (headings), weights 300–700               | SIL Open Font License 1.1 |
| `ibm-plex-sans-latin-variable.woff2` | IBM Plex Sans (interface text), weights 400–600 used | SIL Open Font License 1.1 |

The Open Font License allows bundling the fonts with software, including commercial use.
